VAD-driven turn-taking with 640ms silence trigger. Transcribe→respond→speak runs as background task so callers can interrupt mid-sentence.

BUILD • CONFIGURE • DEPLOY

From idea to live call in three steps.

1

Build an agent

No Python needed. JSON defines prompt, tools, handoffs, voice.

python3 config_cli.py create-agent
# id, prompt, tools, handoffs,
# rules, model / voice
2

Configure a tool

Declare once in tools.json. Schema drives prompt + type coercion.

"get_weather": {
  "description": "Gets weather",
  "args_schema": {
    "location": {"type": "string",
     "required": true}
  }
}
3

Deploy locally

One process serves one room, N isolated sessions. Free.

livekit-server --dev
ollama pull phi4-mini
python3 transcribe_test.py

Concurrency done right

Every participant gets an independent Session: agent, handoff context, barge-in flag, audio track, MCP client. Track subscription permissions route each answer to only the caller who asked.

Observable by default

Every turn logged stage-by-stage to SQLite: sessions, calls, events, agent_transitions. Open dashboard.html for latency + tool attribution with one query.
